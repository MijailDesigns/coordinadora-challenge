## Coordinadora Challenge

1. Clonar el repositorio
2. Crear un .env basado en el .env.template
3. Ejecuta el comando `npm install` solo si vas a desarrollar de manera local.
4. Ejecutar el comando `docker compose up --build` o `docker compose up --build -d` para ejecutarlo en modo detached, con esto tendras corriendo la base de datos y el proyecto en un solo comando.
5. Encuentra el Swagger en `http://localhost:3000/api`
